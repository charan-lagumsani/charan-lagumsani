### 👨‍💻 About me

Senior AI & ML Engineer with 5+ years across **Citi** (Generative AI Engineer), **Siemens** (Senior ML Engineer), and **Morgan Stanley** (Data Scientist). MS in Data Analytics & Information Systems from **Texas State University** (GPA 3.6). Based in **Austin, TX**.

I specialize in the full GenAI stack: LLM applications on Azure OpenAI, RAG pipelines over complex document corpora, multi-agent workflows with LangGraph, responsible-AI guardrails for regulated industries — and the MLOps platforms that keep it all running at 99.95% uptime.

### ⚡ What I ship

- **Production GenAI** — LLM apps with GPT-4/Claude on Azure OpenAI: portfolio analytics, tax-loss harvesting, KYC onboarding with fine-tuned BERT (5 days → 2 hours)
- **RAG that retrieves** — LangChain + FAISS pipelines over SEC filings and compliance docs at 92% retrieval accuracy
- **Multi-agent AI** — LangGraph systems for trade compliance: 65% faster validation cycles, 98% workflow accuracy
- **Responsible AI** — SEC/FINRA governance guardrails (hallucinations −70%, 100% regulatory adherence), SHAP/LIME/RAGAS evaluation
- **MLOps** — MLflow/Kubeflow/Airflow platforms, Kubernetes CI/CD (release cycles: weeks → 3 hours)
